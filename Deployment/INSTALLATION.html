What Is in the Deployment Folder

Deployment\
  install.bat            ← double-click to install the backend
  install.ps1            ← called automatically by install.bat
  docker-compose.yml     ← backend service definitions
  .env                   ← secrets file — provided by Qalitrack team
  QalitrackHardware.exe  ← hardware client (weighbridge, camera, RFID)
  QalitrackFrontend.exe  ← web frontend desktop app

Prerequisites

Docker Desktop and WSL2 are installed automatically by the script. If a restart is required mid-install, the script will say so — restart the PC and double-click install.bat again to continue.

Part 1 — Backend Services

1
Confirm Docker Desktop is running (whale icon in taskbar).
2
Place the .env file provided for this site inside the Deployment folder (same level as install.bat).
3
Double-click install.bat. Click Yes on the UAC prompt. The script clones the source code, builds all service images, and starts everything. First run takes 5–15 minutes.
4
When the window shows the green success banner, open a browser and verify:
ServiceURL
Gatewayhttp://localhost:7000
User Servicehttp://localhost:7001
Master Datahttp://localhost:7002
Backuphttp://localhost:7003
Transactionshttp://localhost:7004
The backend restarts automatically after every reboot — no action needed.

Part 2 — Hardware Client

Collects weighbridge data, camera feed, RFID and NFC reads.

1
Right-click QalitrackHardware.exe → Run as administrator.
2
Fill in the setup wizard:
  • Weighbridge — TCP (IP + port, default 3002) or Serial (COM port + baud rate from the weighbridge manual)
  • Camera — IP, RTSP port (554), path, username/password
  • RFID — tick if installed, enter IP + port (2022)
  • NFC — tick if installed, select COM port
3
Click Install Service. The service starts automatically and survives reboots.
4
Verify at http://localhost:5000.
Update: run the new QalitrackHardware.exe as Administrator — the wizard pre-fills the existing config and the button reads Update & Reinstall.

Part 3 — Frontend

The Qalitrack web application desktop client.

1
Double-click QalitrackFrontend.exe.
2
Follow the on-screen installation steps and accept the defaults.
3
Launch the application from the desktop shortcut created by the installer.
Update: run the new QalitrackFrontend.exe — the installer upgrades in place.

Troubleshooting

SymptomFix
install.bat says "restart required" Restart the PC, then double-click install.bat again. This happens once when WSL2 or Docker Desktop is installed for the first time.
install.bat reports Docker not running Open Docker Desktop manually, wait for the whale icon to be solid, then re-run install.bat.
install.bat reports .env not found Place the .env file in the same folder as install.bat and re-run.
install.bat reports WSL not installed Run wsl --install in PowerShell as Administrator, restart the PC, re-run install.bat.
Services show unhealthy after install Wait 60 seconds — databases take time on first boot. Open a browser and check the URLs again.
Hardware: "Installation Failed" Right-click QalitrackHardware.exe → Run as administrator. Administrator rights are required.
Weighbridge shows no data (TCP) Confirm IP and port with the site engineer. Test: ping <ip> in PowerShell.
Weighbridge shows no data (Serial) Confirm COM port in Device Manager. Check baud rate against the weighbridge manual.
Camera not connecting Test the RTSP stream in VLC: Media → Open Network Stream → rtsp://user:pass@ip:554/path. The service retries automatically.

Updating the Backend

Re-run install.bat — it pulls the latest code and rebuilds the images. Existing data is preserved.
