Qalitrack Manned only. This guide covers Qalitrack Manned. Qalitrack Unmanned has its own installation guide.

What Is in the Deployment Folder

Everything needed to install Qalitrack on a site is contained in the Deployment folder, handed to the installer as a single package.

install.batDouble-click to install the backend — the only file you need to run
install.ps1The PowerShell script called automatically by install.bat
docker-compose.ymlDefines all backend services
.envSite-specific secrets — provided by the Qalitrack team, do not modify
QalitrackHardware.exeHardware client installer (weighbridge, camera, RFID, NFC)
QalitrackFrontend.exeFrontend desktop application installer

Part 1 — Backend Services

The backend runs as Docker containers. Docker Desktop and WSL2 install automatically if missing — no manual setup required. If a restart is needed mid-install the script will say so; restart the PC and double-click install.bat again.

  1. 1
    Place the .env file provided for this site in the same folder as install.bat.
  2. 2
    Double-click install.bat and click Yes on the Windows security prompt. The script clones the source into WSL2, builds all service images, and starts everything. First run: 5–15 minutes.
  3. 3
    When the green banner appears, verify these addresses in a browser:
    ServiceURL
    Gatewayhttp://localhost:7000
    User Servicehttp://localhost:7001
    Master Datahttp://localhost:7002
    Backuphttp://localhost:7003
    Transactionshttp://localhost:7004
The backend restarts automatically on every reboot. To update, re-run install.bat — it pulls the latest code and rebuilds while preserving all data.

Part 2 — Hardware Client

The hardware client collects weight readings, camera video, and optionally RFID or NFC reads. It runs as a Windows Service and starts on boot.

Right-click QalitrackHardware.exe and choose Run as administrator. The setup wizard opens — fill in the details for this site:

  1. 1
    Weighbridge — choose TCP and enter the IP and port (default 3002), or choose Serial and enter the COM port and baud rate from the weighbridge manual.
  2. 2
    Camera — enter the IP address, RTSP port (usually 554), stream path, and login credentials.
  3. 3
    RFID / NFC — tick only if the reader is physically installed and enter the connection details.
  4. 4
    Click Install Service and verify at http://localhost:5000.
Update: run the new exe as Administrator — it pre-fills the existing config and the button reads Update & Reinstall.

Part 3 — Frontend

Double-click QalitrackFrontend.exe, follow the on-screen steps, and accept the defaults. A desktop shortcut is created when the installer finishes. To update, run the new QalitrackFrontend.exe — it upgrades in place.

Troubleshooting

SymptomFix
install.bat says restart requiredRestart the PC and re-run install.bat. Happens once on first install.
Docker not runningOpen Docker Desktop, wait for the whale icon, then re-run install.bat.
.env not foundPlace .env next to install.bat and re-run.
WSL not installedRun wsl --install as Administrator, restart, re-run.
Services unhealthyWait 60 s — databases take time on first boot.
Hardware install failedMust run as Administrator.
Weighbridge — no data (TCP)Confirm IP and port. Test: ping <ip>.
Weighbridge — no data (Serial)Check COM port in Device Manager and baud rate in the manual.
Camera not connectingTest in VLC: rtsp://user:pass@ip:554/path. Service retries automatically.
