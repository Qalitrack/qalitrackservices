Prerequisites

Docker Desktop and WSL2 are installed automatically by the script. If a restart is required mid-install the script will tell you — restart the PC and double-click install.bat again.

Part 1 — Backend Services

  1. 1
    Confirm Docker Desktop is running (whale icon in the taskbar).
  2. 2
    Place the .env file provided for this site in the same folder as install.bat.
  3. 3
    Double-click install.bat and click Yes on the UAC prompt. The script installs WSL2 and Docker Desktop if missing, clones the source, builds all images, and starts every service. First run: 5–15 minutes.
  4. 4
    When the green banner appears, verify in a browser:
    ServiceURL
    Gatewayhttp://localhost:7000
    User Servicehttp://localhost:7001
    Master Datahttp://localhost:7002
    Backuphttp://localhost:7003
    Transactionshttp://localhost:7004
The backend restarts automatically after every reboot — no action needed.

Part 2 — Hardware Client

Collects weighbridge data, camera feed, RFID and NFC reads.

  1. 1
    Right-click QalitrackHardware.exe → Run as administrator.
  2. 2
    Fill in the setup wizard:
    • Weighbridge — TCP (IP + port, default 3002) or Serial (COM port + baud rate)
    • Camera — IP, RTSP port 554, path, username/password
    • RFID — tick if installed, enter IP + port (2022)
    • NFC — tick if installed, select COM port
  3. 3
    Click Install Service. Starts automatically, survives reboots.
  4. 4
    Verify at http://localhost:5000.
Update: run the new exe as Administrator — wizard pre-fills existing config, button reads Update & Reinstall.

Part 3 — Frontend

The Qalitrack web application desktop client.

  1. 1
    Double-click QalitrackFrontend.exe.
  2. 2
    Follow the on-screen steps and accept the defaults.
  3. 3
    Launch from the desktop shortcut created by the installer.
Update: run the new QalitrackFrontend.exe — upgrades in place.

Troubleshooting

SymptomFix
install.bat says "restart required"Restart the PC then double-click install.bat again. Happens once when WSL2 or Docker Desktop installs for the first time.
Docker not runningOpen Docker Desktop, wait for the whale icon to be solid, re-run install.bat.
.env not foundPlace .env in the same folder as install.bat and re-run.
WSL not installedRun wsl --install in PowerShell as Administrator, restart, re-run install.bat.
Services unhealthyWait 60 s — databases take time on first boot. Recheck the URLs.
Hardware: Installation FailedMust run QalitrackHardware.exe as Administrator.
Weighbridge no data (TCP)Confirm IP and port. Test: ping <ip> in PowerShell.
Weighbridge no data (Serial)Confirm COM port in Device Manager. Check baud rate against weighbridge manual.
Camera not connectingTest in VLC: rtsp://user:pass@ip:554/path. Service retries automatically.

Updating the Backend

Re-run install.bat — pulls latest code and rebuilds. Existing data is preserved.
