🏗️ Level 0: Foundation Data (Pure Reference Tables)

1A Location Types

✅ No dependencies - Can be created first

Create Plant, Warehouse, Terminal, Branch classifications

Sample: Plant (PLT), Warehouse (WHR), Terminal (TRM), Branch (BRC)

1B Zones

✅ No dependencies - Can be created first

Create regional zones for Kenya operations

Sample: Coastal Region (COAST), Eastern Region (EAST), Central Region (CENTRAL)

1C Product Categories

✅ No dependencies - Root categories first

Create product category hierarchy (Root → Child)

Sample: Cement → OPC/PPC, Clinker, Raw Materials

1D Packaging Types

✅ No dependencies - Pure reference

Create packaging method references

Sample: 50kg Bags, 25kg Bags, Bulk, Container

2A Sites

2B Business Entities

✅ No dependencies - Core business entities

Create customers, suppliers, transporters

Sample: ABC Construction Ltd, Sunrise Builders, Kenya Limestone Quarries, Coastal Gypsum Suppliers

2C Vehicles & Drivers

✅ No dependencies - Fleet management
