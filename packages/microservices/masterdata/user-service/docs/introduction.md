# Introduction

The **User Service Microservice** is a robust API designed for managing user authentication, roles, permissions, and reporting. This service ensures secure access to system resources through JWT-based authentication and role-based access control (RBAC).

### Key Technologies:
- **Backend:** ASP.NET Core (C#)
- **Authentication:** JWT (JSON Web Tokens)
- **Access Control:** RBAC (Role-Based Access Control)
- **Database:** SQLite
- **API Documentation:** Swagger UI for interactive API documentation and testing

The API includes endpoints for:
- User login, logout, and password management
- Role and permission management
- Shift assignment
- Generating comprehensive reports related to users and shifts
