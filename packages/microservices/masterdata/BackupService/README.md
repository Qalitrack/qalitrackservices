# BackupService Documentation

This directory contains the DocFX configuration for generating API documentation for the BackupService.

## Prerequisites

- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- [DocFX](https://dotnet.github.io/docfx/)

## Building Documentation

1. Ensure XML documentation is generated by building the projects:
   ```bash
   dotnet build
   ```

2. Install DocFX (if not already installed):
   ```bash
   dotnet tool install -g docfx
   ```

3. Build the documentation:
   ```bash
   docfx build
   ```

4. Serve the documentation locally:
   ```bash
   docfx serve _site
   ```

The generated documentation will be available in the `_site` directory.

## Configuration

The `docfx.json` file contains the configuration for:
- API metadata extraction from the .NET projects
- Content organization
- Build settings

## Adding Content

- Add Markdown files to the root or `articles/` directory
- API documentation is automatically generated from XML comments in the code
